# 定位与商业化（2026-09-27 定盘）

> 这是战略结论存档。动手优先级、版本范围见 README「待补」；本文件回答"为什么这么做"和"钱从哪来"。

## 一、产品是什么

**一套你自己拥有的多语精听底座。** 输入任意语言、任意播客的 RSS，产出词级时间戳转写 + 双语逐句对照，全部在本地跑、部署在自己的 Cloudflare 上。

**语言不是底座的属性。** 英→中、中→日、西→韩用的是同一个引擎、同一种数据契约，换的只是语言对——中英那一版只是它的一个实例。这不只是产品洁癖，是分发战略：底座一旦语言无关，"第一市场 / 第二市场"就消失了，只剩"实例"；而 X 上那六七千粉丝本来就是国际受众，**它从第一天起就是全球产品，不需要先证明中国再出海**。

产品真正要占领的不是"用户心智"这种抽象资产，而是**用户每天训练听力的那三分钟**——习惯。心智靠声量（一夜爆红也能一夜蒸发），习惯靠产品设计（走不掉）。所以每个功能都要问：它让"明天还会回来用"这件事更容易吗？

底座四条契约（README 首页同款）：无需注册 / 数据即纯 JSON / 本地处理 / 语言无关。

## 二、三种形态，一种底座

| 形态 | 角色 |
|---|---|
| 流水线底座（`scripts/`） | 引擎：fetch → transcribe → translate → align |
| agent skill（`skills/`） | 引流侧翼 + 信任凭证：让 agent 跑通一次，就是一次带转化钩子的演示 |
| 现成实例（pod.cherina.app） | 门面 + 本项目自用部署；未来可作为"零配置托管版" |

Skill 引来的用户以技术型为主，与"语言学习者"交集有限——**它是信任侧信道和种子用户池，不是主增长引擎**。学习者的主增长引擎是内容（B 站 / 小红书 demo 视频）和口碑。

## 三、商业化：开核（open-core）

**基础能力永久免费且完整可用**，付费只卖增量。免费版阉割 = 断掉流量源头 = 付费无水可承。

**赞助不进软件**：受众画像（技术型、隐私敏感、愿意自部署）是 adblock 命中率最高、自托管动机本身就是躲广告的群体。赞助的正确位置是受众聚集处——X 内容联名、开源仓库赞助位、工具公司付费推广。软件保持干净，关系用来赚钱。

**五条变现线**（按可开启时机）：

| 线路 | 时机 | 说明 |
|---|---|---|
| 捐赠（爱发电 / GitHub Sponsors） | 立刻 | 免费策略的默认配套，零成本 |
| 开源赞助位 | 有 1000+ 星 | 受众即开发者，是 AI 工具 / VPN / 语言服务想触达的 |
| 付费社群 / 30 天精听营 | 有 100 人时 | **最快见钱，且是习惯养成器**（双料） |
| 托管版订阅 | 有活跃用户后 | 云同步 / 移动端复习 / 一键开通；Cloudflare 边际成本极低 |
| 买断 / 终身支持包 | 有口碑后 | 现金快、运维少，适合自部署人群（参考 Migaku $399 终身） |
| B 端（机构版 / 企业内训） | 有案例后 | 卖"部署 + 内容 + 方法"，不是卖软件 |
| 内容授权（帮播客打开中文市场） | 有受众数据后 | 正向循环：免费工具养出学习者规模，规模本身成了播客方想付费的分发渠道 |

结论一句话：**做的是受众公司，软件是沉淀受众的管道。** 收款：海外 Paddle，国内艺爪 / Waffo 一类可提现支付宝的通道；插件商店本身不收款（Chrome 商店收款 2021 年已下线）。

## 四、市场格局（2026-09 调研，时效会过期）

调研的两个市场其实是**同一个底座的两个实例**，不是先后关系——底座语言无关之后，任何语言对都是一次配置，不是重新做一遍。

**中文市场（中国人学英语）**：需求被验证——可可英语、每日英语听力等听力平台活了十几年；最直接竞品是 **ListenLeap 播客学语言**（移动 App，Podcast + 双语字幕 + AI 精听，已扩多语种），另有 Trancy / 沉浸式翻译 / 一字幕等插件"顺带"支持播客。**空位在：桌面浏览器里、用户自带任意播客、就地转写就地精听、完整训练闭环（听→查→跟→写→记）的插件。**

**老外学中文**：趋势向上——Duolingo 美国中文学习者一年暴涨 216%（2025-01）；HelloChinese $69.99/年 证明付费意愿；Du Chinese（4.8 分、1.1 万+ 评价）验证了"真实语料 + 点词查词"模式；Migaku（$9–14/月 Chrome 插件）验证"沉浸式插件订阅"在西方跑得通。**空位在：中文播客的原生听力训练层**（现有产品偏阅读、偏课本音频）。这是底座的**第二个实例**（英→中之外的 中→英 方向），不是第二市场：受众本来就是全球的，差别只在语料和语言对。

## 五、与 Cherina 的关系

同一套基座换语言对 = 新增一个实例；Cherina 的内容图谱（Hanzi→Phrase 本体）是基座上的知识垂直，播客流水线是听力垂直。中文学习实例比英文实例多两层：拼音行是刚需、跟读卖点变成"声调对比"、查词要支持单字与词两级（正好咬合 Cherina 本体）。

**排期**：中英那一份（pod.cherina.app）跑在前面，但它的角色是**第一个实例 + 门面**，不是"第一市场"。Cherina 主产品尚在内测（无 testimonials），不在其验证完成前开第二个正面战场。
