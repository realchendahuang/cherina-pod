# PRD · 播客精听讲义 skill（cherina-pod）

> 2026-10-31 重写，替代旧版“多语精听底座”PRD。旧的定位与托管方案已废弃。
> 用户调研见 `private/调研/小红书-播客精听-2026-10.md`。

## 1. 一句话

**一句话让 agent 把一期英文播客做成“可打印的双语精听讲义”，讲义上每一段都印着二维码，手机一扫就能逐句精听。**

纸负责看和写，手机负责听。两者靠二维码连起来。

## 2. 为什么做

小红书调研（32 篇笔记）的结论：

- 学习者最缺的是**带双语原文的材料**：“在哪听”“有没有文本”“字幕能不能中英对照”出现 25 次以上，还有很多人在评论区找 AI “提取字幕”。
- 学习者第二缺的是**练习方法**：方法帖收藏率最高（例如冰屿yu 8004 赞、7380 藏）。
- 有人在纸上精听、订正，把“能打印”当成工具的优点。
- 精听类 App 已经很多，用户嫌贵、只能用苹果、安装包太大。纸质讲义 + 扫码网页不需要装任何 App。

纸质讲义的老问题是“听”和“看”分离：拿着讲义，还要在手机上拖进度条找那一句。二维码解决的就是这个问题。

## 3. 用户

| 用户 | 场景 | 他们要什么 |
|---|---|---|
| **讲义制作者 / 卖家**（主力付费方） | 小红书上做英语听力资料的博主和店主，卖电子版或实体讲义 | 一次生成一整套排好版、带二维码的讲义；能批量做；能放自己的品牌 |
| **学习者**（最终使用者） | 四六级、雅思、高中生，中低水平；打印讲义，扫码听 | 扫码就能听，不装 App、不登录；能逐句循环、慢速、盲听 |
| **agent 用户**（种子） | WorkBuddy、Claude Code 等 agent 用户，自己给自己做讲义 | 一句话出结果 |

## 4. 输入

| 输入 | 必需 | 说明 |
|---|---|---|
| 哪一期 | ✅ | 播客名 + 描述、RSS + 第几集、Apple Podcasts 链接、本地音频，任选其一 |
| 语言对 | 可选 | 默认英 → 中；中 → 英同一条流水线 |
| 用户水平 | 可选 | 影响难点讲解深浅，例如“四级”“雅思 6” |
| 讲义选项 | 可选 | 分段长度、品牌名或 logo、页脚文字、二维码基础地址 |
| 翻译 key | ✅（一次配置） | 任意 OpenAI 兼容端点 |
| 转写方式 | 自动 | Apple Silicon 默认 mlx-whisper 本地转写；其他机器用 DashScope |

## 5. 输出

一期生成一个文件夹 `out/<episode-id>/`：

| 文件 | 内容 | MVP |
|---|---|---|
| `handout.pdf` | 打印讲义（A4）：见第 6 节 | ✅ |
| `site/` | 扫码后打开的精听网页 + 音频 + 数据，可直接部署到任意静态托管 | ✅ |
| `handout.html` | 讲义的 HTML 源文件，用浏览器打开可预览、可再打印 | ✅ |
| `notes.md` | 本期 20 个左右的难点表达：原句、时间点、讲解 | ✅ |
| `bilingual.json`、`transcript.json` | 数据，供其他工具使用 | ✅ |
| `anki.csv` + 句子音频 | 带原句音频的听力卡片 | 第二版 |

## 6. 讲义排版

- 把一期切成若干**段**，每段 1–3 分钟、按句子边界切分。
- 每段一个区块：
  - 段标题、时间范围（例如 `03:12–05:40`）
  - **段二维码**，放在区块右上角，约 2.5 × 2.5 cm
  - 句子列表：编号、原文、译文；原文下方留一行空白供听写或订正
- 页首：节目名、单集名、难度标签（语速 词/分钟）。
- 页尾：品牌名（可配置）、页码。
- 讲义末尾：本期难点表达表、四步精听法说明。
- 可选“听写版”：只印编号和空行，原文和译文放在后面的答案页。

## 7. 二维码规则

- **一段一个码**，不做一句一个码（码太多会让讲义没法看）。
- 二维码内容：`<base_url>/<episode-id>/#seg=<段号>`，`base_url` 由制作者配置。
- 扫码后直接定位到该段，自动从段首开始播放。
- 二维码纠错等级 M，打印尺寸不小于 2 cm，保证普通手机能识别。
- 讲义首页额外印一个“整期”二维码，打开整期精听页。

## 8. 扫码后的精听网页（`site/`）

- 纯静态页面，手机优先，不登录、不装 App。
- 打开即定位到对应段，大字显示当前句。
- 功能：逐句播放、上一句 / 下一句、单句循环、0.75 / 1.0 / 1.25 倍速、盲听（隐藏文字）、显示原文 / 译文切换。
- 四步练习引导：盲听 → 逐句精听 → 对照译文 → 再盲听，每段结束提示自评。
- 进度存在浏览器本地。
- 支持锁屏播放控制（Media Session API）。

## 9. 部署（二维码要有地址才能扫）

`site/` 是一个静态文件夹，需要放到公网上，二维码才能打开。skill 提供：

- `--base-url`：制作者填自己的静态托管地址（Cloudflare Pages、GitHub Pages、腾讯云 COS 等），二维码按这个地址生成。
- 可选的一键发布命令：先支持 Cloudflare Pages。
- 没有填 `base-url` 时，只生成讲义和本地网页，二维码区域打印为占位符并给出提示。

音频随 `site/` 一起部署，保证字幕和音频严格对齐。

## 10. 不做

- 不做原生 App、浏览器插件、小程序。
- 不做账号、托管服务、公共内容库。
- MVP 不做中文分词、拼音、声调、跟读打分。

## 11. 商业化

- skill 本身开源。
- 收入来源（按先后）：
  1. 你自己用 skill 做讲义，在小红书发方法帖引流。
  2. 面向讲义卖家的会员：批量生成、品牌定制、更好的排版模板、托管 `site/` 的地址。
  3. 精听营：讲义 + 打卡陪练。

## 12. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 版权 | 卖家用 BBC 等节目做讲义出售，属于对他人作品的复制、翻译和商业使用，可能被投诉下架 | skill 只是工具；文档提示使用者自行确认内容授权；我们自己的示例和售卖内容优先用 CC、公有领域或自制材料 |
| 二维码失效 | 卖家的托管地址停用后，已卖出的纸质讲义扫不开 | 文档建议用长期稳定的托管；第二版考虑可迁移的短链 |
| 扫码体验差 | 手机浏览器自动播放受限 | 打开后显示一个大的“开始播放”按钮，由用户点一次 |

## 13. MVP 验收

1. 一句话生成：给出一期 RSS + 集数，skill 产出 `handout.pdf`、`site/`、`notes.md`。
2. 打印 `handout.pdf`，用 iPhone 和安卓相机各扫 3 个段二维码，都能打开并定位到对应段、点一次即开始播放。
3. 精听网页在手机上能完成单句循环、倍速、盲听，锁屏后能继续播放和切句。
4. 一期 60 分钟节目从提交到出结果不超过 20 分钟（不含音频下载）。
