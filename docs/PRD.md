# PRD · 播客精听讲义 skill（cherina-pod）

> 2026-10-31 重写，替代旧版“多语精听底座”PRD。旧的定位与托管方案已废弃。
> 用户调研见 `private/调研/小红书-播客精听-2026-10.md`。

## 1. 一句话

**一句话让 agent 把一期英文播客做成一节精听课：一个本地精听网页 + 一份可打印的双语讲义。**

网页负责听（逐句、循环、盲听），讲义负责看和写。可选在讲义上印二维码，扫码打开在线精听页，但这需要制作者自己有公开网址，不是必需功能。

## 2. 为什么做

小红书调研（32 篇笔记）的结论：

- 学习者最缺的是**带双语原文的材料**：“在哪听”“有没有文本”“字幕能不能中英对照”出现 25 次以上，还有很多人在评论区找 AI “提取字幕”。
- 学习者第二缺的是**练习方法**：方法帖收藏率最高（例如冰屿yu 8004 赞、7380 藏）。
- 有人在纸上精听、订正，把“能打印”当成工具的优点。
- 精听类 App 已经很多，用户嫌贵、只能用苹果、安装包太大。纸质讲义 + 扫码网页不需要装任何 App。

纸质讲义的老问题是“听”和“看”分离：拿着讲义，还要拖进度条找那一句。讲义上印每段的时间范围和句子编号，配合精听网页按编号跳转，就能对上；有公开网址的制作者还可以加印二维码。

## 3. 用户

| 用户 | 场景 | 他们要什么 |
|---|---|---|
| **学习者**（主力） | 四六级、雅思、高中生，中低水平；在电脑或手机上精听，打印讲义订正 | 不装 App、不登录；能逐句循环、慢速、盲听；有双语原文 |
| **讲义制作者 / 卖家** | 小红书上做英语听力资料的博主和店主，卖电子版或实体讲义 | 一次生成排好版的讲义；能批量做；能放自己的品牌；有公开网址时可加二维码 |
| **agent 用户**（种子） | WorkBuddy、Claude Code 等 agent 用户，自己给自己做讲义 | 一句话出结果 |

## 4. 输入

| 输入 | 必需 | 说明 |
|---|---|---|
| 哪一期 | ✅ | 播客名 + 描述、RSS + 第几集、Apple Podcasts 链接、本地音频，任选其一 |
| 语言对 | 可选 | 默认英 → 中；中 → 英同一条流水线 |
| 用户水平 | 可选 | 影响难点讲解深浅，例如“四级”“雅思 6” |
| 讲义选项 | 可选 | 分段长度、品牌名或 logo、页脚文字 |
| `--qr-base-url` | 可选 | 公开网址；填了才在讲义上印二维码 |
| 翻译 key | ✅（一次配置） | 任意 OpenAI 兼容端点 |
| 转写方式 | 自动 | Apple Silicon 默认 mlx-whisper 本地转写；其他机器用 DashScope |

## 5. 输出

一期的产物都在 `episodes/<episode-id>/`：

| 文件 | 内容 | MVP |
|---|---|---|
| `player.html` + `audio/` | 精听网页，双击打开、离线可用：见第 8 节 | ✅ 核心 |
| `handout.html` | 打印讲义（A4）：见第 6 节；浏览器打印存为 PDF | ✅ |
| 可部署的 `site/` | 精听网页的静态版本，供有公开网址的人部署，二维码指向它 | 可选 |
| `notes.md` | 本期 20 个左右的难点表达：原句、时间点、讲解 | ✅ |
| `bilingual.json`、`transcript.json` | 数据，供其他工具使用 | ✅ |
| `anki.csv` + 句子音频 | 带原句音频的听力卡片 | 第二版 |

## 6. 讲义排版

- 把一期切成若干**段**，每段 1–3 分钟、按句子边界切分。
- 每段一个区块：
  - 段号、段标题、时间范围（例如 `03:12–05:40`），和精听网页里的段号一致
  - 句子列表：编号、原文、译文；原文下方留一行空白供听写或订正
  - 可选：段二维码（见第 7 节）
- 页首：节目名、单集名、难度标签（语速 词/分钟）。
- 页尾：品牌名（可配置）、页码。
- 讲义末尾：本期难点表达表、四步精听法说明。
- 可选“听写版”：只印编号和空行，原文和译文放在后面的答案页。

## 7. 二维码（可选，优先级低）

- 只有填了 `--qr-base-url`（必须是公开网址）才生成；不填时讲义上不留任何二维码位置。
- 一段一个码，内容为 `<qr_base_url>/<episode-id>/#seg=<段号>`，扫码后定位到该段。
- 打印尺寸不小于 2 cm。
- 部署 `site/` 由使用者自己负责，skill 不内置发布命令。

## 8. 精听网页（`player.html`）

- 纯静态单页，双击打开、离线可用；同一份页面也是可部署的 `site/` 版本。
- 桌面和手机都能用，不登录、不装 App。
- 支持 `#seg=<段号>` 定位到指定段，大字显示当前句。
- 功能：逐句播放、上一句 / 下一句、单句循环、0.75 / 1.0 / 1.25 倍速、盲听（隐藏文字）、显示原文 / 译文切换。
- 四步练习引导：盲听 → 逐句精听 → 对照译文 → 再盲听，每段结束提示自评。
- 进度存在浏览器本地。
- 支持锁屏播放控制（Media Session API）。

## 9. 不做

- 不做原生 App、浏览器插件、小程序。
- 不做账号、托管服务、公共内容库。
- MVP 不做中文分词、拼音、声调、跟读打分。

## 10. 商业化

- skill 本身开源。
- 收入来源（按先后）：
  1. 你自己用 skill 做讲义，在小红书发方法帖引流。
  2. 面向讲义卖家的会员：批量生成、品牌定制、更好的排版模板。
  3. 精听营：讲义 + 打卡陪练。

## 11. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 版权 | 卖家用 BBC 等节目做讲义出售，属于对他人作品的复制、翻译和商业使用，可能被投诉下架 | skill 只是工具；文档提示使用者自行确认内容授权；我们自己的示例和售卖内容优先用 CC、公有领域或自制材料 |
| 二维码失效（仅启用二维码时） | 公开网址停用后，已打印的讲义扫不开 | 文档提示使用长期稳定的网址 |
| 手机自动播放受限 | 浏览器禁止页面自动出声 | 打开后显示一个大的“开始播放”按钮，由用户点一次 |

## 12. MVP 验收

1. 一句话生成：给出一期 RSS + 集数，skill 产出 `player.html`、`handout.html`、`notes.md`。
2. 双击 `player.html` 离线可用，能完成逐句播放、单句循环、倍速、盲听；讲义上的段号能在网页里直接跳转。
3. 讲义 A4 打印排版正常，原文、译文、听写空行清晰。
4. （可选）填了 `--qr-base-url` 时，讲义印出段二维码，部署 `site/` 后扫码能定位到对应段。
5. 一期 60 分钟节目从提交到出结果不超过 20 分钟（不含音频下载）。

## 13. 里程碑

| 阶段 | 内容 |
|---|---|
| M1 | 用现有一期 `bilingual.json` 做出 `player.html` 和打印讲义原型 |
| M2 | 接入流水线，打包成 skill，跑通一句话生成 |
| M3 | 你自己用 2–4 周，在小红书发内容验证需求 |
| M4 | 面向卖家的批量与品牌定制；可选二维码 |

## 14. v0.2 改进（2026-10-31，已实现）

基于用户路径分析的 7 个断点：

| 断点 | 方案 | 实现 |
|---|---|---|
| 装上用起来 | `--setup` 交互式填 Key 写入 `~/.config/cherina-pod/.env`；`--doctor` 的修复建议改为可直接执行的命令 | `scripts/lesson.py` |
| 选内容 | 内置 17 档已核实可搜到的播客目录，`--recommend --level` 按水平推荐；课程库和段落显示语速 | `scripts/catalog.json` |
| 手机上练 | 20 分钟以内自动生成内嵌音频的单文件课；长节目 `--phone --parts`；`--serve` 局域网课程库（支持 Range，iPhone 可播放） | `build_lesson.py --single-file`、`lesson.py --serve` |
| 广告 | 模型标区间 + 规则兜底（单句且不在首尾、无广告用语的不删），删除后重新编号，播放时跳过空隙 | `build_lesson.py detect_ads`、`ads.json` |
| 记得住 | 书签收藏，课程库里“先听后看”的间隔复习（忘了 10 分钟 / 模糊 ×1.2 / 记住 ×2.5） | `player.html`、`index.html` |
| 坚持 | 课程库：连续天数、近 7 天打卡、今日分钟、累计段数、继续练习 | `episodes/index.html` |
| 晒出去 | 结果页一键生成 1080×1440 分享卡片（手机走系统分享，电脑下载） | `player.html shareCard` |

未做（留待反馈）：本地 ASR、听写比对、Anki 导出、影子跟读、YouTube。

已知限制：
- 学习记录存在 localStorage。Chromium 下所有 `file://` 页面共享存储（已实测）；Safari / Firefox 对本地文件的存储隔离更严格，课程库可能读不到各课进度，此时用 `--serve` 打开。
- 单文件课在 iPhone 上需要用 Safari 打开，微信内置浏览器和“文件”预览不执行脚本。尚未在真机上验证。
